# Event Registration App 

##  Project Overview
The **Event Registration App** is a user-friendly mobile application designed to help users explore events, view event details, and register for their favorite events easily. The application provides a simple and attractive interface with a modern purple and black theme.

##  UI Design Preview

![Event Registration App UI Design](assets/event-registration-ui.png)

##  Screens Included

1. **Splash Screen** – Displays the app branding and event-themed background.
2. **Welcome Screen** – Introduces the application and provides a Get Started option.
3. **Login Screen** – Allows users to sign in using their username, email, and password.
4. **Home Screen** – Displays featured events and navigation options.
5. **Events Screen** – Allows users to browse, search, and filter available events.
6. **Event Registration Screen** – Displays event details and provides a registration option.
7. **Success Screen** – Confirms successful registration with a congratulatory message.

##  Key Features

- Attractive and modern user interface.
- User login and authentication interface.
- Browse and search for events.
- Filter events by category.
- View event details, dates, and timings.
- Easy event registration interface.
- Registration success confirmation.
- Simple bottom navigation for easy access.

##  Tools Used

- **Figma** – UI/UX design and prototyping.

##  Project Objective

The main objective of this project is to design a simple, visually appealing, and user-friendly event registration application that makes discovering and registering for events convenient.

##  Future Enhancements

- User account creation and profile management.
- Online ticket booking and payment integration.
- Event reminders and notifications.
- QR code-based event tickets.
- Admin dashboard for event management.

##  Conclusion

The Event Registration App UI design demonstrates the complete user journey, from opening the application to successfully registering for an event. The design focuses on usability, consistency, and an engaging visual experience.
